# Live build contract (backend ↔ page ↔ patient screen)

Shared spec so three builders can work in parallel. All data is synthetic.

## Origins (badge on every brief line)
- `live`   — produced by a model call in this server session (streamed)
- `saved`  — loaded from `out/brief.json` (an earlier model run)
- `sample` — `fixtures/sample_brief.json`, hand-written, NOT model output
`GET /api/brief` returns `brief.origin` = `saved` or `sample`, plus `brief.generated_at` (ISO) when known.

## GET /api/brief  (extended)
```
{ "brief": {..., "origin": "saved"|"sample", "generated_at": "...", "validation_problems": [...]},
  "state": {...}, "audit": {...}|null,
  "inputs": [ {"name": "Fax packet (12 pages)", "kind": "pdf",  "url": "/data/outside_records_fax.pdf"},
              {"name": "Pharmacy fills",        "kind": "csv",  "url": "/data/pharmacy_fills.csv"},
              {"name": "Intake form",           "kind": "md",   "url": "/data/intake_form.md"},
              {"name": "Patient input (pharmacist-approved)", "kind": "patient", "url": "/patient", "approved": true|false} ],
  "raw": {"prompt": "/out/prompt.txt"|null, "response": "/out/response_raw.txt"|null,
          "brief": "/out/brief.json"|null, "audit": "/out/audit.json"|null} }
```
Every input is invented data; the page stamps each "invented data".

## POST /api/generate/stream   (Server-Sent Events, text/event-stream)
- `event: start`   data `{"model": "...", "timeout_s": 60, "sources": ["fax","fills","intake", "patient"?]}`
- `event: delta`   data `{"text": "<chunk of raw model text>"}`   (many)
- `event: done`    data `{"brief": {... "origin": "live", "validation_problems": [...]}}`
- `event: error`   data `{"detail": "...", "fallback": {brief with origin saved|sample}}`
- `event: timeout` data `{"detail": "No complete brief after 60 s", "fallback": {brief}}`
Timeout = env `COVIGIL_TIMEOUT` (default 60 s) for the whole call. `out/brief.json` is only overwritten after a successful parse, so it is always the last good brief. The raw prompt is written to `out/prompt.txt` before the call (PDF shown as a placeholder line, not base64) and the raw text to `out/response_raw.txt` as it streams. Old `POST /api/generate` stays working.

## GET /out/{name}
Allowlist only: `prompt.txt`, `response_raw.txt`, `brief.json`, `audit.json`, `state.json`, and files in `out/patient_photos/`. `eval/` is never served.

## Patient screen API  (page at `GET /patient` → `app/static/patient.html`)
- `GET /api/patient` →
```
{ "medicines": [ {"id": "metformin", "drug": "Metformin", "dose": "1000 mg", "how": "Morning and night",
                  "from": ["intake", "fills"], "bottle_photo": "/data/bottles/metformin.jpg"|null} ...],
  "answers": { "<id>": {"answer": "taking"|"not_taking"|"unsure", "note": "", "at": "..."} },
  "photos": [ {"med_id": "metformin"|null, "url": "...", "kind": "sample"|"upload", "at": "..."} ],
  "review": {"status": "pending"|"approved"|"returned", "note": "", "by": "", "at": ""} }
```
  Medicines = intake-form table ∪ OTC list ∪ drugs filled in the fill history (e.g. apixaban appears even with no bottle). Answers reset the review to `pending`.
- `POST /api/patient/answer` `{"med_id", "answer", "note"}`
- `POST /api/patient/photo` multipart `file`, form field `med_id` (optional) → saved to `out/patient_photos/`
- `POST /api/patient/photo/sample` `{"med_id"}` → attaches the invented `/data/bottles/<med_id>.jpg` (demo shortcut)
- `POST /api/patient/review` `{"status": "approved"|"returned", "note", "by": "Pharmacist"}` → logged in `state.log` as `{"type": "patient_review", ...}`
- `POST /api/patient/reset`
Only when `review.status == "approved"` does the model call get a fourth source: a text block summarising the answers, plus each photo as an image block. Nothing a patient enters reaches the physician without the pharmacist approving it.

## Invented bottle photos
`data/bottles/<id>.jpg` for ids: metformin, losartan, lisinopril, furosemide, tamsulosin, atorvastatin, naproxen, vitamin_d. No apixaban bottle (the intake says there is none). Each label says SYNTHETIC. Generated by `scripts/make_bottle_photos.py`.
